0712：本周
计划在新实验室重新做实验，流程如下
1.配置5：1的三甲氧基硅烷：二甲氧基硅烷的硅烷原液60g，搅拌12h。应该有成品
2.抽取15g硅烷原液，加入15gN-N二甲基乙酰胺，配比1：1，12h搅拌，应该有现成的乙酰胺。
3.1、2中两步的混合溶液中，取10g加入0.64g正丙醇锆、1.72gpvp、2g葡萄糖，搅拌6h：命名为A液体；另外取20g（2）中的溶液加入1.72gPVP搅拌6h：命名为B液
4.b液体10ml纺织，1.5ml/
5.纺织完成后，取A液体10ml纺织，1.5ml/h
6.纺织完成后，取B液体10ml纺织，1.5ml/h
7.4、5、6中务必连续纺织，中间不要间断。
8.揭下纺织物，送去理学楼227纺织，从常温开始，200min到200摄氏度保温1h，然后从200摄氏度400min升温到900摄氏度保温1h，然后自然炉冷。
9.联系杜斌做sem
