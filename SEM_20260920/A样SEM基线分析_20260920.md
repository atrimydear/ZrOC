## 0. 一句话结论

烧结后的 A 样仍是**连续、无粘连塌陷的纤维网**，纤维直径中位数 **≈ 0.50 μm**，表面带 **50–100 nm 纵向沟槽/条纹**，含 **分级孔隙**（nm 级缝 / 0.1–0.6 μm / 数 μm 束间空隙），**未见致密外壳、颗粒突起、珠粒与断裂**——基线工艺成立，但"苦瓜"结构（致密壳 + 疏松芯 + 表面突起）尚未形成，需靠 B 组（预氧化）对比与截面形貌验证。

## 2. 方法

1. **预处理**：裁除底部信息栏（132 px）；灰度化。
2. **分割**：高斯平滑 σ = 3 px（压制表面沟槽造成的伪分割）→ Otsu 阈值 → 二值闭运算 r = 3（把沟槽"焊回"整根纤维）→ 开运算去噪 → 剔除面积 < 300 px 的碎块。
3. **纤维直径**：距离变换（EDT）脊线法，直径 = 2 × EDT × 像素尺寸，取**中位数**与 IQR（交汇处会将多根纤维合并、使直径偏大，故不用均值）；并用**扫描线断宽法**做交叉对照。
4. **孔隙**：用不做闭运算的分割（保留孔隙）取背景，8 连通标记，等效直径 = 2√(A/π)；区分开孔（与图像边界相连）与闭孔。
5. **表面条纹间距**：中央方形区域高通滤波（减去 σ = 8 高斯）→ 加汉宁窗 → 2D FFT → 径向平均功率谱 → 在 30–1200 nm 周期带内取主峰。

### 标定校验（关键）

程序自动测出信息栏中标尺条的像素长度：**实测 199 px vs 标称 200 px**（各倍率一致，误差 1 px）。
→ 像素尺寸标定与代码实现均通过校验，后续数值可直接换算为物理量。

| 倍率 | 台位① 中位数 | 台位① IQR | 台位② 中位数 | 台位② IQR | 扫描线法中位数（偏大，仅对照） |
|---|---|---|---|---|---|
| 20k | 0.257 μm | 0.16–0.49 | 0.600 μm | 0.27–0.92 | 0.71 / 0.74 μm |
| 15k | 0.460 μm | 0.17–0.74 | 0.393 μm | 0.18–0.68 | 0.80 / 0.53 μm |
| 10k | 0.500 μm | 0.28–0.65 | 0.498 μm | 0.30–0.84 | 0.74 / 0.65 μm |
| 5k | 0.520 μm | 0.38–0.78 | 0.594 μm | 0.40–0.94 | 0.75 / 0.89 μm |
| 3k / 2k | 0.509 / 0.501 μm | 0.33–0.77 | 0.600 μm (2k) | 0.38–0.96 | 0.75 / 0.90 μm |
| 1k | — | — | 0.800 μm | 0.50–1.30 | 1.10 μm |

**结论**：**纤维直径中位数 ≈ 0.50 μm**（台位① 0.50、台位② 0.55），IQR 约 0.27–0.84 μm，分布较宽；20k 图偏细（0.26 μm）与低倍图偏粗（0.80 μm）属分割尺度效应，5k–15k 区间最稳定。两个台位一致 → **样品在约 0.3 mm 尺度上无宏观不均匀**。

### 3.2 孔隙结构（表面统计）

| 倍率 | 孔隙率(void) | 闭孔数 | 等效孔径中位数 | IQR | p90 |
|---|---|---|---|---|---|
| 20k | 0.397 / 0.444 | 720 / 1011 | 0.012 / 0.011 μm | 0.006–0.021 | 0.03–0.04 μm |
| 15k | 0.428 / 0.547 | 568 / 948 | 0.016 / 0.014 μm | 0.008–0.028 | 0.04–0.06 μm |
| 10k | 0.444 / 0.495 | 706 / 1189 | 0.024 / 0.023 μm | 0.013–0.044 | 0.07 μm |
| 5k | 0.528 / 0.562 | 823 / 1015 | 0.039 μm | 0.023–0.065 | 0.11 μm |
| 3k | 0.635 / 0.636 | 515 / 539 | 0.060 / 0.062 μm | 0.038–0.107 | ≈0.47 μm |
| 2k | 0.629 | 426 | 0.116 μm | 0.063–0.327 | 1.26 μm |
| 1k | 0.658 | 544 | 0.586 μm | 0.259–1.231 | 2.22 μm |

**结论**：
- 孔隙呈**分级结构**：10–30 nm 级细缝（高倍，部分接近分割极限，谨慎视为孔）、**0.1–0.6 μm 级**（2k/1k 可靠）、数 μm 级束间空隙；
- **表面孔隙率随倍率单调上升**（20k 0.40 → 1k 0.66）：低倍统计的是束间大空隙，高倍只看纤维间小缝 → **孔隙率只能在同倍率下横向比较**；
- 与图像边界连通的数 μm–数十 μm 大空隙被计为开孔，未纳入闭孔统计。

## 4. 定性观察（视觉模型判读 + 分割结果复核）

- 连续纤维成网，纤维间交织良好；
- **无大片致密膜/板结区**；
- 表面可见**纵向沟槽/条纹**（与 3.3 定量一致）；
- 低倍（2k/1k）看呈**蓬松团块状、厚薄不均**，团块之间存在数 μm–数十 μm 大空隙；
- **未见明显珠粒、断裂端、大颗粒或碎屑**；
- 细纤维与交叉重叠处存在少量漏分割（分割方法的已知局限）。

## 6. 局限

1. **无截面图** → 无法判断"致密壳 + 疏松芯"，苦瓜结构的核心验收项缺失；
2. **无前驱体（未烧结）同批样品** → 无法定量给出陶瓷化收缩率；
3. **表面 SEM ≠ 体相**：孔隙率、比表面需 BET 确认；
4. **高倍下 10–30 nm"孔"** 接近分割极限，可能是并丝处的细缝或算法伪影；
5. 无 EDS/XRD/Raman 数据，Zr 分布与自由碳状态未验证；
6. 单个样品的 6 个倍率不能替代多样品统计。

---

## 7. 下一步建议

1. **补 A0（无糖）同倍率 SEM**：孔径/孔隙率之差才是糖的造孔贡献；
2. **补截面 SEM**（烧结后样品切样）：验证是否出现壳-芯结构；
3. **今后每批纺完留一小块前驱体毡做 SEM**：得到收缩率，直接支撑"预氧化成壳能否抗收缩"的判断；
4. **对比规则（固定下来）**：
   - 孔隙率/孔径：**必须同倍率、同方法**比较；
   - 直径：用 EDT 脊线**中位数 + IQR**，不用均值（交汇处会偏大）；
   - 条纹间距：20k/15k/10k 三档取平均。
5. 待办表征：BET（体相孔隙）、EDS（Zr 分布）、Raman（自由碳）、XRD（相组成）。
